# Hello World

A simple Java program that prints `Hello, World!` to the console.

## Project Structure

```text
.
├── HelloWorld.java
└── README.md
```

## Requirements

* Java Development Kit (JDK)

## How to Run

Compile the Java file:

```bash
javac HelloWorld.java
```

Run the program:

```bash
java HelloWorld
```

## Output

```text
Hello, World!
```

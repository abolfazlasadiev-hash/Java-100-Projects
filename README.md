# Java 100 Projects

A structured collection of 100 Java projects designed to build a strong Java foundation before moving into Java Backend development.

## Goal

The goal is to learn Java by building projects instead of only studying theory.

This repository focuses on:

- Java Fundamentals
- Conditions and Loops
- Arrays
- Strings
- Object-Oriented Programming
- Collections
- Exceptions
- File I/O
- Generics
- Lambda Expressions
- Functional Interfaces
- Stream API
- Optional
- Date and Time API
- Algorithms
- Data Structures
- Real-World Console Applications

## Recommended Java Version

JDK 17 or newer.

## Learning Method

For every project:

1. Read the README.
2. Study the required theory.
3. Implement the project yourself.
4. Test normal cases.
5. Test edge cases.
6. Refactor the code.
7. Commit the project to Git.

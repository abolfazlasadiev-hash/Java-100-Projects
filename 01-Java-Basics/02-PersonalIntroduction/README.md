# Personal Introduction

## Goal

Create a simple Java program that prints a person's basic information, including:

* Name
* Age
* City
* Other personal details

## Example Output

```text
Name: Alex
Age: 25
City: Tehran
Occupation: Student
```

## How to Run

Compile the program:

```bash
javac PersonalIntroduction.java
```

Run it:

```bash
java PersonalIntroduction
```
